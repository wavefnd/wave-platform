## 주요 연산자

| 분류 | 연산자 |
| --- | --- |
| 산술 | `+`, `-`, `*`, `/`, `%` |
| 비교 | `==`, `!=`, `<`, `<=`, `>`, `>=` |
| 논리 | `&&`, `||`, `!` |
| 비트 | `&`, `\|`, `^`, `~`, `<<`, `>>` |
| 대입 | `=`, `+=`, `-=`, `*=`, `/=`, `%=` |
| 증감 | `++`, `--` |
| 주소·역참조 | `&value`, `deref pointer` |
| 명시적 형 변환 | `as` |

```wave
var width: i32 = 12;
var area: i32 = width * 8;
var large: bool = area >= 64;
var widened: i64 = area as i64;
area += 8;
```

## 우선순위

파서의 큰 흐름을 높은 우선순위에서 낮은 우선순위로 정리하면 다음과 같습니다.

1. 기본식과 후위 접근: 함수 호출, 필드 접근, 인덱싱, 후위 `++`·`--`
2. 단항 연산: `!`, `~`, `&`, `deref`, 전위 `++`·`--`, 단항 `+`·`-`
3. `as` 형 변환
4. `*`, `/`, `%`
5. `+`, `-`
6. `<<`, `>>`
7. `<`, `<=`, `>`, `>=`
8. `==`, `!=`
9. 비트 `&`, `^`, `|`
10. `&&`, `||`
11. 대입과 복합 대입

대입은 오른쪽 식을 다시 대입식으로 파싱하므로 연쇄 대입은 오른쪽 결합 방식으로 해석됩니다. 읽기 어려운 혼합식은 괄호로 의도를 명확히 하십시오.

## 대입 가능한 대상

대입과 `++`·`--`는 변수, 필드, 배열 인덱스, 역참조처럼 저장 위치를 나타내는 식에 사용합니다. 불변 `let`과 `const`에 대한 쓰기는 허용되지 않습니다.

## 예약된 연산 철자

`is`와 `xnand`는 lexer 토큰으로 존재하지만 위 표현식 파서 계층에는 구현된 연산으로 연결되어 있지 않습니다. 따라서 사용할 수 있는 연산자로 문서화하지 않습니다.
