## 모듈 분류

| 영역 | 모듈 |
| --- | --- |
| 핵심 데이터 | string, math, bytes, buffer |
| 시스템 | sys, env, path, time, process |
| 입출력 | io, fs, net |
| 네이티브 지원 | libc, mem |

이 목록은 릴리스 매니페스트에 선언된 모듈 목록입니다. 이후 모든 API의 존재를 보장하지 않습니다. 정확한 함수 시그니처는 설치된 소스를 확인하십시오.
