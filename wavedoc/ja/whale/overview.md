## はじめに

Whaleは、プログラミング言語の実装とコンパイラツールのための汎用コンパイラツールチェーンです。タイプを持つ中間表現（IR）、AMD64アセンブラ、オブジェクトファイルライブラリ、リンカベースの機能を提供します。各コンポーネントは、Rustライブラリと`whale`コマンドで使用されます。

IRは、機械語エンコーディングとは無関係に計算の意味を表します。アセンブラはマシンコマンドをエンコードして再配置可能なオブジェクトを生成します。オブジェクトライブラリはセクション・シンボル・再配置を表現します。リンカはオブジェクト間の参照を解決し、実行可能ファイルを配置します。

|コンポーネント|提供されるインターフェース|制限|
| --- | --- | --- |
|アセンブラ|AMD64アセンブリ内のELF64再配置可能オブジェクトの作成|コマンドとディレクティブのサポート範囲が不完全|
|オブジェクトライブラリ|オブジェクト構成、payloadなしBSS、ターゲット検証、サイズを検査するAMD64ELF64シリアライゼーションと選択可能なWaveレコードの実装|再配置可能オブジェクトは実行可能ファイルではありません|
| IR | 構築、印刷、署名チェックされた直接/間接呼び出し、バージョン付き AST の引き下げ、ターゲットの検証、タイプ レイアウトのチェック | AST format 2、typed IR format 4、正確なビット定数、テキスト読み取り・検証・往復出力に対応。機械語呼び出し生成は未対応 |

未定義の動作を禁止する規則は、検証済みのIRとトレースメモリに適用されます。実験的実装にはメモリ・実行参照文書のランタイム検査がまだすべて実装されていません。

## ビルドとアセンブル

Rust1.86.0以上でビルドします。

```sh
git clone https://github.com/wavefnd/Whale.git
cd Whale
cargo build --release --locked
```

次のアセンブリを`answer.asm`として保存します。

```asm
section .text
global answer

answer:
    mov eax, 42
    ret
```

ELF64オブジェクトを作成します。

```sh
./target/release/whale asm --amd64 answer.asm -o answer.o
```

Whaleの独自のアセンブラを使用するため、外部アセンブラは必要ありません。結果には呼び出し可能な関数が含まれており、プロセスの開始コードは含まれません。

実験的なAST→IRコマンドは`--features socket-cli`でビルドすると使用できます。 CLIのコマンドは[コマンドリファレンス](/docs/ja/whale/whale-cli)を参照してください。

## ライブラリの使用と診断

実行またはコード生成の前にIRを確認する必要があります。入力エラーとbuilder誤用は構造エラーとして返されます。ライブラリの入力エラーがホストプロセスを終了したり、既存の内容を上書きしたりしないでください。信頼できない入力を受け取るツールでは、リソース制限を調整できる必要があります。

同じツールチェーンのバージョン・入力・ターゲット・設定は決定的な出力を生成しなければなりません。配布物のメタデータは、バージョン・commit・使用可能な機能を識別します。 CIは、各インタフェースに対して通常入力、拒否する入力、trap、O0保存、round-trip、native実行の意味を確認します。開発・検証命令は[Whale貢献案内](https://github.com/wavefnd/Whale/blob/master/CONTRIBUTING.md)を参照してください。
