## 行コメント

`//` から行末までがコメントになります。

```wave
var count: i32 = 10; // アクティブなリクエスト数
```

## ブロックコメント

`/*` と `*/` でブロックコメントを囲みます。

```wave
/* コメントは複数行に
   またがって記述できます。 */
```

ブロックコメントは入れ子にできます。

```wave
/* 外側のコメント
   /* 内側のコメント */
   再び外側のコメント
*/
```

## 文字列内のコメント記号

文字列リテラルと文字リテラルの内側にある `//`、`/*`、`*/` は、コメントの区切りではなく文字どおりのテキストです。

```wave
var text: str = "https://wave-lang.dev";
```

## 閉じられていないブロックコメント

すべての `/*` には対応する `*/` が必要です。閉じられていないブロックコメントには診断 `E1002`（`UnterminatedComment`）が発生します。

広い範囲を一時的にコメントアウトするときは、入れ子の深さが正しく釣り合っていることを確認してください。
