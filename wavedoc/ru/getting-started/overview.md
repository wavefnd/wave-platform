## О Wave

Wave — статически типизированный язык системного программирования с генерацией машинного кода и явным низкоуровневым управлением.

## Первая программа

```wave
fun main() {
    println("Hello, Wave!");
}
```

Сохраните файл как `main.wave` и запустите:

```shell
wavec run main.wave
```

## Объявление переменных

Локальные переменные объявляются с помощью `var`.

```wave
var count: i32 = 1;
count += 1;
```

Прежние формы `let` и `let mut` удалены и теперь являются синтаксической ошибкой. Для объявлений верхнего уровня используются `const` и `static`.

## Состояние перевода

Непереведённые страницы явно помечаются и показываются на английском языке.
