## Введение

Whale — это набор инструментов компилятора общего назначения для реализаций языков программирования и инструментов компилятора. Предоставляет типизированные промежуточные выражения (IR), ассемблер AMD64, библиотеку объектных файлов и функции на основе компоновщика. Каждый компонент используется через библиотеку Rust и команду `whale`.

IR выражает семантику вычислений независимо от кодировки машинного языка. Ассемблер кодирует машинные инструкции для создания перемещаемых объектов. Библиотеки объектов представляют разделы, символы и перестановки. Компоновщик разрешает ссылки между объектами и помещает исполняемый файл.

|компонент|Предоставляемый интерфейс|предел|
| --- | --- | --- |
|ассемблер|Создайте перемещаемый объект ELF64 из сборки AMD64.|Неполный охват команд и директив|
|библиотека объектов|Состав объекта, payload без BSS, целевая проверка, AMD64 ELF64 сериализация и выбираемая реализация записи Wave для проверки размера.|Перемещаемые объекты не являются исполняемыми файлами.|

## Сборка и сборка

Сборка с использованием Rust 1.86.0 или выше.

```sh
git clone https://github.com/wavefnd/Whale.git
cd Whale
cargo build --release --locked
```

Сохраните следующую сборку как `answer.asm`.

```asm
section .text
global answer

answer:
    mov eax, 42
    ret
```

Создайте объект ELF64.

```sh
./target/release/whale asm --amd64 answer.asm -o answer.o
```

Он использует собственный ассемблер Whale, поэтому внешний ассемблер не требуется. Выходные данные содержат вызываемую функцию и не содержат кода запуска процесса.

Экспериментальные команды AST→IR доступны при сборке с `--features socket-cli`. Информацию о команде CLI см. в [Справочник команд](/docs/ru/whale/whale-cli).

## Использование библиотеки и диагностика

IR необходимо проверить перед выполнением или генерацией кода. Ошибки ввода и неправильное использование builder приведут к возврату структурных ошибок. Ошибки ввода в библиотеке не должны завершать хост-процесс или перезаписывать существующее содержимое. Инструменты, которые принимают ненадежные входные данные, должны иметь возможность корректировать ограничения ресурсов.

Одна и та же версия инструментальной цепочки, входные данные, цель и конфигурация должны давать детерминированный результат. Метаданные дистрибутива идентифицируют версию·commit·и доступные функции. CI проверяет правильность ввода, ввод отклоняется, trap, O0 сохранение, round-trip, native семантика выполнения для каждого интерфейса. Команды разработки/проверки см. в разделе [Whale Информация о вкладе](https://github.com/wavefnd/Whale/blob/master/CONTRIBUTING.md).
