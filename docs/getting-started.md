# Getting started

## Create an account

Open the site, select **Create account**, and enter a display name and recovery email. Scan the displayed QR code with a TOTP authenticator and confirm its six-digit code. The platform creates a Wave email address from the display name. For example, `John Mark` becomes `john-mark@example.org` when `example.org` is the configured domain.

The same account is used across all services.

## Mail

Open **Mail** to send and receive ordinary email. Use the compose button to enter an internal Wave address or an external email address. Community posts and questions use the message storage system internally but do not appear in personal mail folders.

## Community

Open **Community** to browse posts by space. Signed-in users can create posts where posting is enabled, comment on a post, and reply directly to another comment.

The **LunaStev** area is a separate publishing space. Its posts are owner-managed, while signed-in users can participate through comments.

## Questions

Open **Questions** to ask about Wave, add tags and version information, or answer an existing question. Accepted-answer and voting controls appear only when the current account is allowed to use them.

## Documentation

Open **Documentation** and choose a documentation language. The interface stays
English/Korean, while documentation has its own language preference and an
explicit English fallback for pages awaiting translation. Public community
posts and comments are English-only; the LunaStev owner space is exempt.

## Source

**Source** is a read-only view of mirrored Git repositories. It supports repository, branch, tag, commit, tree, file, and README browsing. Changes must be made in the upstream repository.

## Administration

The **Administration** item is visible only to the platform owner and administrators. It shows live platform statistics and module availability.
